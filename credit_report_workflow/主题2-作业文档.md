# 主题2：作业文档

## 对公信贷尽调报告生成工作流改造

## 一、作业目标

通过改造现成的工作流模板，加深对以下知识点的理解：

1. 工作流编排的节点划分与执行顺序
2. 状态在不同节点之间的传递方式
3. 风险规则判断的可配置性
4. 可控文本生成中的"模板 + LLM 增强"组合方法
5. 大模型调用失败时的降级兜底思维



## 二、作业背景

宁波银行某支行客户经理需要为一家**纺织服装类企业**撰写授信尽调报告。根据行业经验，企业的应收账款周转天数普遍较长（90-120 天），销售净利率通常低于机械制造企业。

你需要基于 `theme2-report-flow` 案例模板，修改企业数据和风险规则，生成一份适合该企业的尽调报告初稿。

**关于 LLM 模式的说明：**本作业**要求**必须调用真实大模型

## 三、任务要求

### 任务 1：替换企业数据（25 分）

在 `input_step.py`（或 Java 的 `InputStep.java`）中，将企业数据替换为以下信息：

| 字段 | 新值（数据为举例参考） |
|------|------|
| 企业名称 | 宁波纺织贸易有限公司 |
| 行业 | 纺织服装 |
| 年营业收入 | 8000 万元 |
| 净利润 | 480 万元 |
| 应收账款周转天数 | 110 天 |
| 总资产 | 5000 万元 |
| 总负债 | 2800 万元 |

### 任务 2：调整风险规则（25 分）

在 `risk_assessment_step.py`（或 Java 的 `RiskAssessmentStep.java`）中，根据纺织服装行业特点，增加或调整风险规则：

1. 应收账款周转天数超过 100 天的，提示"应收账款周转天数超过100天，行业账期较长，回款风险需重点关注"
2. 销售净利率低于 6% 的，提示"销售净利率偏低，议价能力或成本控制能力需关注"

### 任务 3：调整报告格式（20 分）

在 `report_generation_step.py`（或 Java 的 `ReportGenerationStep.java`）中，修改报告模板，在"初步结论"前增加一个"行业提示"部分：

```markdown
行业提示
该企业所属纺织服装行业，应收账款周期普遍较长，建议重点关注下游客户回款情况及存货周转效率。
```

### 任务 4：运行并提交说明（30 分）

1. 运行改造后的代码，保存输出结果截图
2. 撰写 300 字以内的说明，包含：
   - 你修改了哪些内容
   - 修改后的风险判断结果有哪些变化
   - 若尝试了 LLM 模式，结论段落与 Mock 模式有何不同
   - 你认为"模板保底 + LLM 增强"的设计对银行场景有什么价值

## 六、参考步骤

### Python 版本

1. 打开 `theme2-report-flow/python/input_step.py`
2. 修改企业数据
3. 打开 `theme2-report-flow/python/risk_assessment_step.py`
4. 修改风险规则
5. 打开 `theme2-report-flow/python/report_generation_step.py`
6. 修改报告模板（在适当位置插入"行业提示"）
7. 运行 `python3 main.py`
8. 截图保存输出

**可选：开启 LLM 增强模式**

```bash
# 在运行前设置环境变量
export LLM_API_KEY="你的API密钥"
python3 main.py
```

### Java 版本

1. 打开 `theme2-report-flow/java/InputStep.java`
2. 修改企业数据
3. 打开 `theme2-report-flow/java/RiskAssessmentStep.java`
4. 修改风险规则
5. 打开 `theme2-report-flow/java/ReportGenerationStep.java`
6. 修改报告模板
7. 编译运行：
   ```bash
   javac *.java
   java Main
   ```
8. 截图保存输出

**可选：开启 LLM 增强模式**

```bash
# 在运行前设置环境变量
export LLM_API_KEY="你的API密钥"
javac *.java
java Main
```



## 七、预期输出示例

```text
尽调报告初稿
============

一、企业基本信息
企业名称: 宁波纺织贸易有限公司
所属行业: 纺织服装
年营业收入: 8000万元
净利润: 480万元

二、财务指标分析
销售净利率: 6.0
资产负债率: 56.0
应收账款周转次数: 3.32

三、风险判断
- 应收账款周转天数超过100天，行业账期较长，回款风险需重点关注
- 销售净利率偏低，议价能力或成本控制能力需关注
- 资产负债率超过50%，杠杆水平偏高

四、行业提示
该企业所属纺织服装行业，应收账款周期普遍较长，建议重点关注下游客户回款情况及存货周转效率。

五、初步结论
建议结合行业周期及客户上下游账期进一步核实，审慎核定授信额度。
```
